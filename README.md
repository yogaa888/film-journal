# 观影手账 · Film Journal

一个懂我的观影手账：记录电影、美剧到具体季集，并用 AI 帮我把随口的想法变成值得留下的文字。移动端优先的 Web 应用，作品集项目。

## 现已实现

- **时间线**：按观看日期倒序，顶部本周概览 + 横向海报条，支持按状态/类型筛选、按日期/评分排序
- **三粒度记录**：电影 / 剧 / 单集，记到具体季集；弃剧强制填写弃剧集数与原因
- **五维评分**：剧情 / 表演 / 画面 / 后劲 / 重看意愿，细横条展示，综合分自动计算
- **详情页**：大图海报背景、原生 SVG 五维雷达图、同导演/同演员关联记录
- **观影日历热力图**：最近 18 周的观影密度，点格子看当天片单
- **搜索 / 片单 / 我的**：关键词搜索、手动收藏夹、统计概览、JSON 导入导出

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5173/`。首次进入自动写入 3 条示例数据。

## 设计说明

- 数据全部存在浏览器 localStorage，无后端、无登录、单用户；读写集中在 `src/data/store.ts`，以后换云端只改这一处。
- 综合分权重在 `src/config/scoring.ts`，五维等权平均。
- AI 接口与 prompt 配置将在后续版本接入，密钥从环境变量读取，不进代码仓库。

## 技术栈

Vite + React + TypeScript，无路由库（hash 路由），无图表库（SVG 手绘雷达图）。
